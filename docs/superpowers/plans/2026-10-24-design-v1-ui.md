# design-v1 UI 改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/design-v1/` 四张设计图重构桌宠三个界面（气泡、对话输入条、设置·对话记录），并把整套设计 token（色板/圆角/投影/字号/交互状态）落地为 CSS 变量、清掉现有深色主题。

**Architecture:** 渲染层新增 `styles/tokens.css`（:root 变量，图 04 规范的原值固化），`styles/index.css` 全部改引用变量；气泡改为「尾巴尖端锚定模型头部左上角上方 16px」+ 弹出/淡出动画（`PetModel` 新增窗口坐标 `anchor` getter，纯函数 `modelTopLeft`/`bubbleOffsets` 承载换算）；`ChatPanel` 重写为单行输入条（默认/输入中/生成中三态 + 4000 字计数 + 错误重试行），窗口扩展高度 240→120；新建 `pet/settings/` 设置面板（覆盖整窗、扩展 key `'settings'`），对话记录页读 `chatStore` 数据（搜索/分组/导出/清空）。支撑能力：Go 新增 `DELETE /api/v1/history`（清空消息、保留会话）、主进程新增 `lovelybuddy:export-file` IPC（保存对话框 + 写 Markdown）。

**Tech Stack:** React 18 + zustand + vitest（前端）；Go + gin + pgx（后端，新增一个 DELETE 端点）；新增前端依赖仅 `@fontsource/inter`（latin 子集）。

**Spec:** `docs/design-v1/README.md` + 四张设计图（`01-bubble.png` 气泡形态 / `02-input.png` 输入条状态 / `03-settings.png` 设置·对话记录 / `04-specs.png` 状态与规范）；产品基线 `docs/design.md`（M3 设置面板方向）。图内逐项标注的转写（含 OCR 与取色）已在本计划各任务中逐条引用，执行时以本计划为准、不重复读图。

## 关键决策（README/图未细化处的裁定）

1. **token 落位**：全部设计 token 集中在 `styles/tokens.css` 的 `:root` 变量，`index.css` 只引用变量、不再出现裸色值。图只覆盖三个界面，未覆盖的既有组件（右键菜单、无模型占位卡、导入面板）按 token 规则推演同风格（奶油底 + 墨绿字 + 薄荷强调），作为「整体设计 token」范围一并迁移。
2. **字体**：Inter 经 `@fontsource/inter` 打包（latin 子集，数字/拉丁）；Sarasa Gothic SC 体积大不随包分发，font stack 置顶声明、缺失回退 macOS 自带 PingFang SC。`font-family` 拉丁优先（`'Inter', 'Sarasa Gothic SC', 'PingFang SC', …`），数字/拉丁走 Inter、中文走 Sarasa/PingFang。
3. **气泡锚点 = 模型包围盒左上角**（全身体模型头顶≈包围盒顶部）：`PetModel` 新增 `anchor`（窗口坐标 getter，由 `modelTopLeft` 从模型中心锚点与显示尺寸换算——windowAnchor 位移后仍准确，菜单/聊天/设置扩展量叠加时天然正确）。尾巴尖端在其上方 16px（图 01「留 16px 呼吸距离」）；模型未加载时回退旧居中样式。
4. **设置面板形态**：覆盖整窗的对话框（`position: fixed; inset`），窗口扩展 key `'settings'`、目标 960×600，被工作区夹紧时面板填满实际窗口（侧栏/会话列表定宽、消息流弹性收缩）；打开时模型被面板遮挡，关闭走 Esc / 点面板外（与右键菜单一致，面板无 ✕）。
5. **侧栏五入口只有「对话记录」本期可用**：形象管理/模型与连接/外观与动作/关于 render 为 disabled 占位（M3 设置面板实现），不加占位文案。
6. **「仅保留最近 200 条」落地为 refresh limit 200 + footer 文案**；服务端消息修剪不在本期（记入 M3）。
7. **清空 = 新增 `DELETE /api/v1/history`**（清空默认会话全部消息、保留会话行，单会话模型不变）；**导出 = 主进程 `showSaveDialog`（默认 Downloads）+ fs 写入**，新 IPC `lovelybuddy:export-file`。
8. **错误重试 = `chatStore.retry()`**：去掉本地末尾失败残留的 user 消息后原样重发（离线失败服务端未落库，去掉不留重）；服务端已收而客户端失败的罕见重复由断线恢复 `refresh()` 对齐。
9. **输入条关闭无 ✕**（图 02 无关闭钮）：Esc / 点面板外关闭；面板打开、生成中保持扩展等既有 `useChatPanel` 逻辑不动。
10. **CHAT_H 240→120**（上边距 8 + 输入条 64 + 错误行 24 + 间隙 8 + 头顶 16）；气泡 maxHeight 随锚点上方空间（≈88px）。
11. **交互状态按图 04 原值固化**：悬停上浮 1px+投影加深、按下缩放 0.96+主色加深 8%、输入为空发送键降饱和 40%（仍可聚焦输入框）、焦点描边薄荷 1.5px+外侧 3px 柔光。

## Global Constraints

- **README「实现时别丢的三条」为最高优先级**：① 气泡 `pointer-events: none` 必须保留（纯展示、不吞鼠标、不参与穿透状态机、气泡内不放按钮）；② 输入条打开时气泡隐藏——两者同锚点（共用 `chat` 扩展位）的互斥规则必须保留；③ 对话界面只留输入，历史统一进设置，消息列表不塞回 `ChatPanel`
- **交互逻辑沿用现有代码**：打字机 + 8s 静默淡出 + 不拦鼠标；Enter 发送（IME `isComposing` 不发送）；生成中切换停止键；AbortController 停止语义（半截保留、不算错误）不变
- 窗口扩展仍向左上扩、右下角锚定；`windowAnchor` 与 expand 尺寸必须同步改（本计划只新增 `'settings'` key，不改既有扩展数学）
- `usePassthrough` 无条件发 IPC 规则不破；设置面板打开并入整窗强制不穿透条件（`PetCanvas` 增加 `settingsOpen` prop）
- 产品显示名 **AI桌宠**；用户可见文案禁角色名；测试夹具用中性素材名（haru/shizuku）；console 前缀 `[lovely-buddy]`
- 后端分层单向：dao ← service ← controller ← router；新端点照 M2 落位
- 测试：前端放功能目录 `__test__/`（vitest + jsdom + @testing-library/react）；Go 与源码同目录 `*_test.go`；DAO 测试自建会话行、DB 不可达 `t.Skip`
- Commit：Conventional Commits、subject 小写开头，直接提交 main
- 输入 4000 字上限与后端一致（前端 `maxLength=4000`，服务端已有校验）

```ts
import { readFileSync } from 'node:fs'
import { dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'
import { describe, expect, it } from 'vitest'

// 注意：不能写 new URL('../tokens.css', import.meta.url)——Vite 会静态改写该表达式
// （?raw 也会因 vitest 默认 css:false 返回空串）。用裸 import.meta.url + fileURLToPath
// 手工解析，路径不受构建转换影响。
const stylesDir = resolve(dirname(fileURLToPath(import.meta.url)), '..')

function cssOf(name: 'tokens' | 'index'): string {
  return readFileSync(resolve(stylesDir, `${name}.css`), 'utf-8')
}

function varValue(css: string, name: string): string {
  const m = css.match(new RegExp(`--${name}:\\s*([^;]+);`))
  if (!m) throw new Error(`token --${name} 未找到`)
  return m[1].trim()
}

// 设计 token 契约（design-v1/README.md「设计 token」+ 图 04，值即线上规范）
const TOKENS: Record<string, string> = {
  'color-primary': '#5bc8a6',
  'color-primary-deep': '#35a483',
  'color-primary-press': '#54b899',
  'color-accent': '#ffb9c7',
  'color-accent-ink': '#e36f8c',
  'color-bg': '#fbf7f0',
  'color-surface': '#ffffff',
  'color-ink': '#33403b',
  'color-ink-2': '#7c8c86',
  'color-ink-3': '#a6b3ad',
  'color-border': '#efe8de',
  'radius-card': '28px',
  'radius-panel': '24px',
  'radius-bubble': '26px',
  'radius-input': '20px',
  'radius-msg': '16px',
  'radius-pill': '999px',
  'fs-title': '19px',
  'fs-body': '13px',
  'fs-aux': '11px'
}

describe('设计 token 契约', () => {
  it('色板/圆角/字号与 design-v1 规范一致', () => {
    const css = cssOf('tokens')
    for (const [name, value] of Object.entries(TOKENS)) {
      expect(varValue(css, name), `--${name}`).toBe(value)
    }
  })

  it('投影与描边 token 与规范一致', () => {
    const css = cssOf('tokens')
    expect(varValue(css, 'shadow-mint')).toBe('0 12px 32px -6px rgba(91, 200, 166, 0.12)')
    expect(varValue(css, 'shadow-mint-deep')).toBe('0 14px 36px -6px rgba(91, 200, 166, 0.2)')
  })

  it('间距 token 取 4 的倍数（8/12/14/18/24）', () => {
    const css = cssOf('tokens')
    expect(['--sp-1', '--sp-2', '--sp-3', '--sp-4', '--sp-5'].map((n) => varValue(css, n.slice(2)))).toEqual([
      '8px',
      '12px',
      '14px',
      '18px',
      '24px'
    ])
  })
})
```

```ts
import type { Pos } from '../../live2d/windowAnchor'

/** 尾巴尖端距头部左上角的呼吸距离（图 01） */
export const TAIL_GAP = 16
/** 尾巴伸出气泡底缘的高度 */
export const TAIL_H = 8
/** 尾巴距气泡右缘的距离 */
export const TAIL_INSET = 24
/** 气泡与窗口边的内边距 */
export const BUBBLE_INSET = 8

export interface BubbleOffsets {
  right: number
  bottom: number
  maxWidth: number
  maxHeight: number
}

/**
 * 气泡右下锚定换算：尾巴尖端落在 (anchor.x, anchor.y - 16)（头部左上角上方 16px）。
 * 元素 right/bottom 偏移 = 窗口尺寸 − 锚点坐标 ± 尾巴几何；maxWidth/maxHeight 把气泡
 * 夹在窗口与头部上方空间（扩展区）内，负值回 0。
 */
export function bubbleOffsets(anchor: Pos, winW: number, winH: number): BubbleOffsets {
  return {
    right: winW - anchor.x - TAIL_INSET,
    bottom: winH - anchor.y + TAIL_GAP + TAIL_H,
    maxWidth: Math.max(anchor.x + TAIL_INSET - BUBBLE_INSET, 0),
    maxHeight: Math.max(anchor.y - TAIL_GAP - TAIL_H - BUBBLE_INSET, 0)
  }
}
```

```tsx
import { useEffect, useRef, useState, type ReactElement } from 'react'
import { useChatStore } from '../../store/chatStore'
import { getActiveModel } from '../../live2d/modelBus'
import { INTENT_MOTIONS, type MotionIntent } from '../../live2d/motionMap'
import { useTypewriter } from './useTypewriter'
import { bubbleOffsets, type BubbleOffsets } from './bubbleLayout'

/** 流式结束（sending=false）后静默多久淡出（图 01） */
const HIDE_AFTER_MS = 8000
/** 淡出动画时长（CSS .speech-bubble--out transition 同步） */
const FADE_MS = 200

interface Props {
  /** 聊天面板打开时让位（回复显示在面板历史里），气泡隐藏——互斥规则保留 */
  panelOpen: boolean
}

/**
 * 打字机气泡：尾巴尖端锚定模型头部左上角上方 16px（PetModel.anchor），
 * 弹出 Scale 0.72→1.04→1 180ms + 同步淡入，8s 静默后淡出。
 * 纯展示（pointer-events:none，不加 data-interactive、不参与穿透状态机——点击穿到桌面）。
 */
export default function SpeechBubble({ panelOpen }: Props): ReactElement | null {
  const items = useChatStore((s) => s.items)
  const sending = useChatStore((s) => s.sending)
  const lastMotion = useChatStore((s) => s.lastMotion)
  const [phase, setPhase] = useState<'in' | 'out' | 'gone'>('gone')
  const outTimerRef = useRef<number | null>(null)
  const [layout, setLayout] = useState<BubbleOffsets | null>(null)

  const last = items.length > 0 ? items[items.length - 1] : null
  const isReply = last !== null && last.role === 'assistant' && last.content !== ''
  const shown = useTypewriter(phase !== 'gone' && !panelOpen && isReply ? last.content : '')

  // 回复内容变化 → 弹出；面板打开/无回复 → 立即消失；静默 8s → 淡出 200ms → 卸载
  useEffect(() => {
    if (panelOpen || !isReply) {
      setPhase('gone')
      return
    }
    setPhase('in')
    if (sending) return // 流式中不计时；sending 翻 false 会重跑本 effect 起计时
    const id = window.setTimeout(() => {
      setPhase('out')
      outTimerRef.current = window.setTimeout(() => setPhase('gone'), FADE_MS)
    }, HIDE_AFTER_MS)
    return () => {
      window.clearTimeout(id)
      if (outTimerRef.current !== null) {
        window.clearTimeout(outTimerRef.current)
        outTimerRef.current = null
      }
    }
  }, [panelOpen, isReply, sending, last?.content])

  // 锚点定位：窗口 resize（扩展/收起）后重算；无模型回退居中样式
  useEffect(() => {
    const recalc = (): void => {
      const pet = getActiveModel()
      setLayout(pet ? bubbleOffsets(pet.anchor, window.innerWidth, window.innerHeight) : null)
    }
    recalc()
    window.addEventListener('resize', recalc)
    return () => window.removeEventListener('resize', recalc)
  }, [])

  // motion 事件 → 当前模型播动作（seq 去重，一次事件一个动作）
  const seqRef = useRef(0)
  useEffect(() => {
    if (lastMotion === null || lastMotion.seq === seqRef.current) return
    seqRef.current = lastMotion.seq
    if (lastMotion.intent in INTENT_MOTIONS) {
      void getActiveModel()?.playIntent(lastMotion.intent as MotionIntent)
    }
  }, [lastMotion])

  if (phase === 'gone' || panelOpen || !isReply) return null
  const classes = [
    'speech-bubble',
    phase === 'out' ? 'speech-bubble--out' : '',
    layout === null ? 'speech-bubble--center' : ''
  ]
    .filter(Boolean)
    .join(' ')
  const style =
    layout === null
      ? undefined
      : { right: layout.right, bottom: layout.bottom, maxWidth: layout.maxWidth, maxHeight: layout.maxHeight }
  return (
    <div className={classes} style={style} aria-live="polite">
      <div className="speech-bubble-body">{shown}</div>
      <span className="speech-bubble-tail" aria-hidden="true" />
    </div>
  )
}
```

```ts
  // 用户消息不留重；服务端已收而客户端失败的罕见重复由断线恢复 refresh 对齐。
  retry() {
    if (get().sending) return
    const items = get().items
    let tail = items.length
    for (let i = items.length - 1; i >= 0; i--) {
      if (items[i].role === 'assistant' && items[i].content !== '') break // 已有成功回复
      if (items[i].role === 'user') {
        tail = i
        break
      }
    }
    if (tail >= items.length) return
    const text = items[tail].content
    set({ items: items.slice(0, tail), error: null })
    void get().send(text, get().lastAvatar)
  },
```

```tsx
import { useState, type KeyboardEvent, type ReactElement } from 'react'
import { useChatStore } from '../../store/chatStore'

/**
 * 对话输入条（窗口 chat 扩展区顶部）：单行输入 + 发送/停止 + 错误重试行。
 * 只留输入，历史统一进设置（README 铁律）；与气泡同锚点互斥（App 控制）。
 * data-interactive 保证穿透状态机可点。无关闭钮（图 02），关闭走 Esc / 点面板外（useChatPanel）。
 */
export default function ChatPanel(): ReactElement {
  const sending = useChatStore((s) => s.sending)
  const error = useChatStore((s) => s.error)
  const send = useChatStore((s) => s.send)
  const stop = useChatStore((s) => s.stop)
  const retry = useChatStore((s) => s.retry)
  const [value, setValue] = useState('')

  const currentSlug = (): string | undefined => {
    const { models, modelUrl } = usePetStore.getState()
    return models.find((m) => m.url === modelUrl)?.slug
  }

  const submit = (): void => {
    const v = value.trim()
    if (!v || sending) return
    setValue('')
    void send(v, currentSlug())
  }

  const onKeyDown = (e: KeyboardEvent<HTMLInputElement>): void => {
    if (e.key === 'Enter' && !e.nativeEvent.isComposing) submit()
  }

  const typing = !sending && value !== ''
  return (
    <div className="chat-input-wrap" data-interactive onContextMenu={(e) => e.preventDefault()}>
      <div className={`chat-input${typing ? ' chat-input--typing' : ''}`}>
        <input
          autoFocus
          maxLength={4000}
          disabled={sending}
          placeholder={sending ? '回复中…' : '和我说点什么…'}
          value={value}
          onChange={(e) => setValue(e.target.value)}
          onKeyDown={onKeyDown}
        />
        {typing && <span className="chat-count">{value.length}/4000 个字</span>}
        {sending ? (
          <button type="button" className="chat-stop" onClick={stop}>
            停止
          </button>
        ) : (
          <button type="button" className="chat-send" disabled={!typing} onClick={submit}>
            发送
          </button>
        )}
      </div>
      {error !== null && (
        <button type="button" className="chat-error" onClick={retry}>
          {error}·点击重试
        </button>
      )}
    </div>
  )
}
```

```ts
import type { ChatItem } from '../../store/chatStore'

export interface HistoryGroup {
  label: string
  items: ChatItem[]
}

function pad(n: number): string {
  return String(n).padStart(2, '0')
}

function localDay(d: Date): string {
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`
}

function parse(item: ChatItem): Date {
  return item.created_at ? new Date(item.created_at) : new Date()
}

/** 「今天/昨天/M月D日」标签（会话卡与消息流分组共用） */
function dayLabel(isoLike: string | undefined, now: Date): string {
  const d = isoLike ? new Date(isoLike) : now
  const day = localDay(d)
  if (day === localDay(now)) return '今天'
  const yesterday = new Date(now.getFullYear(), now.getMonth(), now.getDate() - 1)
  if (day === localDay(yesterday)) return '昨天'
  return `${d.getMonth() + 1}月${d.getDate()}日`
}

/** 消息流分组：按本地日分组，标签今天/昨天/M月D日；无 created_at（本地新发）归今天 */
export function groupByDay(items: ChatItem[], now: Date = new Date()): HistoryGroup[] {
  const groups: HistoryGroup[] = []
  for (const it of items) {
    const label = dayLabel(it.created_at, now)
    const last = groups[groups.length - 1]
    if (last && last.label === label) last.items.push(it)
    else groups.push({ label, items: [it] })
  }
  return groups
}

/** 搜索过滤：内容大小写不敏感子串；空查询原样返回 */
export function filterChatItems(items: ChatItem[], query: string): ChatItem[] {
  const q = query.trim().toLowerCase()
  if (!q) return items
  return items.filter((it) => it.content.toLowerCase().includes(q))
}

/** 会话卡副标题：`今天 10:24•6条`；无记录「暂无记录」 */
export function sessionSubtitle(items: ChatItem[], now: Date = new Date()): string {
  if (items.length === 0) return '暂无记录'
  const last = parse(items[items.length - 1])
  return `${dayLabel(items[items.length - 1].created_at, now)} ${pad(last.getHours())}:${pad(last.getMinutes())}•${items.length}条`
}

/** 导出文件名：AI桌宠对话-YYYYMMDD-HHmm.md */
export function exportFileName(d: Date): string {
  return `AI桌宠对话-${d.getFullYear()}${pad(d.getMonth() + 1)}${pad(d.getDate())}-${pad(d.getHours())}${pad(d.getMinutes())}.md`
}

/** 对话记录 → Markdown（图 03 footer「可导出为 Markdown」） */
export function historyToMarkdown(items: ChatItem[]): string {
  const lines = ['# AI桌宠对话记录', '']
  const d = new Date()
  lines.push(`> 导出时间：${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())} ${pad(d.getHours())}:${pad(d.getMinutes())}`)
  for (const g of groupByDay(items)) {
    lines.push('', `## ${g.label}`)
    for (const it of g.items) {
      lines.push('', `**${it.role === 'user' ? '我' : 'AI桌宠'}**：${it.content}`)
    }
  }
  return lines.join('\n') + '\n'
}
```

```ts
 * - 递增令牌防「点开又立刻关掉」竞态；Esc / 点面板外关闭
 */
export function useSettingsPanel(): { open: boolean; openPanel: () => void; closePanel: () => void } {
  const [open, setOpen] = useState(false)
  const tokenRef = useRef(0)

  const openPanel = (): void => {
    const token = ++tokenRef.current
    const { extraW, extraH } = settingsExtras(window.innerWidth, window.innerHeight)
    void window.lovelybuddy.expandWindow('settings', extraW, extraH).then(() => {
      if (token !== tokenRef.current) return // 期间已关闭/重开
      setOpen(true)
    })
  }

  const closePanel = (): void => {
    tokenRef.current++
    setOpen(false)
    window.lovelybuddy.collapseWindow('settings')
    window.lovelybuddy.setPassthrough(true) // 立即恢复穿透，交给 usePassthrough 状态机接管
  }

  useEffect(() => {
    if (!open) return
    const onDown = (e: PointerEvent): void => {
      if (e.target instanceof Element && e.target.closest('[data-interactive]')) return
      closePanel()
    }
    const onKey = (e: KeyboardEvent): void => {
      if (e.key === 'Escape') closePanel()
    }
    window.addEventListener('pointerdown', onDown, true)
    window.addEventListener('keydown', onKey)
    return () => {
      window.removeEventListener('pointerdown', onDown, true)
      window.removeEventListener('keydown', onKey)
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [open])

  return { open, openPanel, closePanel }
}
```

```tsx
export default function SettingsPanel(): ReactElement {
  const items = useChatStore((s) => s.items)
  const clear = useChatStore((s) => s.clear)
  const [query, setQuery] = useState('')
  const [exported, setExported] = useState(false)

  useEffect(() => {
    return () => {
      if (exportedTimer.current !== null) window.clearTimeout(exportedTimer.current)
    }
  }, [])

  const doClear = (): void => {
    if (window.confirm('清空全部对话记录？此操作不可恢复。')) void clear()

    const { saved } = await window.lovelybuddy.exportFile(exportFileName(new Date()), historyToMarkdown(items))
    if (saved) {
      setExported(true)
      exportedTimer.current = window.setTimeout(() => setExported(false), 2000)
    }
  }

  return (

      <aside className="settings-side">
        <div className="settings-brand">
          <span className="settings-brand-name">lovely-buddy</span>
          <span className="settings-brand-ver">本地 AI桌宠•v0.1</span>

              disabled={name !== '对话记录'}
            >
              {name}
            </button>
          ))}
        </nav>
      </aside>
      <main className="settings-main">
        <header className="settings-toolbar">
          <input
            className="settings-search"
            placeholder="搜索记录"
            value={query}
            onChange={(e) => setQuery(e.target.value)}
          />
          <button type="button" className="settings-export" onClick={() => void doExport()}>
            {exported ? '已导出' : '导出'}
          </button>
          <button type="button" className="settings-clear" onClick={doClear}>
            清空
          </button>
        </header>
        <div className="settings-body">
          <section className="settings-convs">
            <button type="button" className="conv-card active">
              <span className="conv-title">AI桌宠对话</span>
              <span className="conv-sub">{sessionSubtitle(items)}</span>
```

```tsx
import { useEffect, useRef, type ReactElement } from 'react'
import PetCanvas from './pet/PetCanvas'
import PetMenu from './pet/PetMenu'
import ImportPanel from './pet/ImportPanel'
import ChatPanel from './pet/chat/ChatPanel'
import SpeechBubble from './pet/chat/SpeechBubble'
import SettingsPanel from './pet/settings/SettingsPanel'
import { useChatPanel } from './pet/chat/useChatPanel'
import { usePetMenu } from './pet/usePetMenu'
import { useSettingsPanel } from './pet/settings/useSettingsPanel'
import { usePetStore } from './store/petStore'
import { useChatStore } from './store/chatStore'

export default function App(): ReactElement {
  const modelUrl = usePetStore((s) => s.modelUrl)
  const modelName = usePetStore((s) => s.modelName)
  const placeholderDismissed = usePetStore((s) => s.placeholderDismissed)
  const loadModels = usePetStore((s) => s.loadModels)
  const dismissPlaceholder = usePetStore((s) => s.dismissPlaceholder)
  const { menu, openMenu, closeMenu } = usePetMenu()
  const { open: chatOpen, openPanel, closePanel } = useChatPanel()
  const { open: settingsOpen, openPanel: openSettingsPanel, closePanel: closeSettingsPanel } = useSettingsPanel()

  // 后端健康轮询（5s）
  useEffect(() => {
    let stopped = false
    let timer: number | undefined
    const poll = async (): Promise<void> => {
      try {
        const runtime = await window.lovelybuddy.getRuntime()
        if (stopped) return
        const res = await fetch(`${runtime.baseUrl}/healthz`)
        const h = (await res.json()) as { status: string; db: string; version: string }
        if (stopped) return
        usePetStore.getState().setStatus(h.db === 'ok' ? 'online' : 'offline', h.version)
      } catch {
        if (!stopped) usePetStore.getState().setStatus('offline')
      }
    }
    void poll()
    timer = window.setInterval(() => void poll(), 5000)
    return () => {
      stopped = true
      window.clearInterval(timer)
    }
  }, [])

  useEffect(() => {
    void loadModels()
  }, [loadModels])

  // 启动即拉一次历史（后端未起也不报错，等恢复后过渡刷新兜底）
  useEffect(() => {
    void useChatStore.getState().refresh()
  }, [])

  // 断线恢复：offline → online 时对齐历史（服务端可能落了半截/新消息）
  const status = usePetStore((s) => s.status)
  const prevStatusRef = useRef(status)
  useEffect(() => {
    if (prevStatusRef.current === 'offline' && status === 'online') {
      void useChatStore.getState().refresh()
    }
    prevStatusRef.current = status
  }, [status])

  return (
    <>
      <PetCanvas
        url={modelUrl}
        name={modelName ?? ''}
        menuOpen={menu !== null}
        chatOpen={chatOpen}
        settingsOpen={settingsOpen}
        onMenu={() => {
          if (menu) closeMenu()
          else openMenu()
        }}
      />
      {chatOpen && <ChatPanel />}
      <SpeechBubble panelOpen={chatOpen} />
      {settingsOpen && <SettingsPanel />}
      {modelUrl === null && !placeholderDismissed && (
        <div className="placeholder" data-interactive>
          <button className="placeholder-close" title="暂不显示" onClick={dismissPlaceholder}>
            ×
          </button>
          <p className="placeholder-title">未找到 Live2D 模型</p>
          <p className="hint">支持粘贴 HTTPS zip 链接、选择本地 zip 或目录导入。</p>
          <ImportPanel />
          <div className="placeholder-actions">
            <button onClick={() => void loadModels()}>重新扫描</button>
          </div>
        </div>
      )}
      {menu !== null && (
        <PetMenu
          x={menu.x}
          y={menu.y}
          onClose={closeMenu}
          onChat={() => {
            closeMenu()
            openPanel()
          }}
          onSettings={() => {
            closeMenu()
            openSettingsPanel()
          }}
        />
      )}
    </>
  )
}
```
